# AION Indian Market Intelligence — Rate-Limited Demo

Macro-event and sector impact intelligence for Indian financial markets.

This Space is a demo surface for AION Indian Market Intelligence.

- Demo limit: 3 requests per visitor per day
- Production access requires an API key
- Registration: `https://aionanalytics.in/apis`

Production API contract:

- `POST https://api.aionanalytics.in/v1/analyze`
- header:
  - `X-API-Key: <key>`

This Space is for evaluation only. It is not the supported production runtime.
